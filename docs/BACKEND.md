# Backend contract and guarantees

`uv run uvicorn services.api.main:app --port 8000` runs the API. `uv run python -m services.worker.main` runs the persisted local worker; `--once` claims at most one due job per workspace. The root launcher supplies one shared private data directory and portal service secret. Use `uv sync --all-extras --locked` for the optional AWS adapters. Exact dependency versions and hashes are committed in `uv.lock`; versions were checked against official PyPI JSON metadata on 2026-09-13.

Local sessions are signed HttpOnly SameSite=Strict cookies, with a secret persisted at mode 0600. A new session creates an isolated workspace; switching Alex/Sam requires its existing signed cookie. Local controls require NF_MODE=local and NF_ENVIRONMENT=development. AWS requests accept only API Gateway's validated Clerk JWT claims through Mangum's trusted event scope. The backend validates exact issuer/audience/authorized frontend origin, nf:resident scope, active version-2 user/session claims and expiry. Opaque internal residents derive from the validated issuer and subject. Every admitted resident joins the server-fixed Demo Borough generation; workspace headers or client metadata have no authority. Strongly read admission and disabled-resident checks apply on every request. Private evidence and approval ownership remain per resident. Administrative initialization and reset have no public HTTP endpoint.

## Durable commands

SQLite `BEGIN IMMEDIATE` transactions serialize case changes, approval reservation, and attempt creation. The Dynamo adapter uses the same domain commands, strongly consistent reads, workspace revision checks, and conditional `TransactWriteItems`. Approval stores approver, incident, immutable revision, recipient, action, exact SHA-256 report hash, attachment hashes, and expiry. A repeated approval returns its existing operation. Later timeline, observation, and follower changes never regenerate the approved report. A fresh draft is a new record; a stale or expired revision cannot authorize a write.

Jobs persist due times, attempts, lease owner, lease expiry, principal, and results. The local worker claims one job at a time and recovers interrupted leases. A callback from the browser rechecks the canonical incident, approval expiry, cancellation, and current worker lease immediately before the external click, then persists write-start. Recovery after a possible write records `OUTCOME_UNKNOWN`; it never clicks again. Receipt lookup is an explicitly requested, read-only reconciliation operation. The fictional portal also deduplicates by reserved attempt ID, but external website writes are not claimed to be atomic.

Analysis and routing are bounded jobs returning HTTP 202. Local model outputs are deterministic, explicitly labeled fixtures. AWS invokes real isolated AgentCore Runtime sessions through the three Strands agents; configuration or provider errors remain visible without local fallback. Required location/ownership clarification and trusted registry coverage are checked deterministically outside all model outputs. The fixture's image observation explicitly says it does not perform visual analysis.

## Access patterns

Records are partitioned by authorized workspace and typed keys. Keyset pagination is bounded. Geographic-cell index records are queried in a cell and eight neighboring cells before strongly reading candidates, checking category, time and asset identity, measuring actual distance, and requiring resident confirmation. A confirmed link updates membership and observations without creating a second draft or submission workflow. Added observations can be unlinked by their owner; the original observation and append-only unlink event remain. Unlinking never changes a frozen submission.

Direct membership keys avoid scanning observations. Per-incident event/subscription indexes and per-user case/subscription/notification indexes avoid losing later records in other cases. A pending-job index excludes finished work. Normal Dynamo paths use `Query`, never table scans, and submission locks never depend on eventual indexes. The local development reset uses a workspace-only inventory to remove indexed fixture records and refuses active worker leases.

This MVP bounds a geographic cell to 100 records, normal list pages to 50 records, timeline projection to the most recent 100 events (with a separate paginated events endpoint), 20 followers per incident, and active local job retrieval to 500. Dense production jurisdictions require capacity/pagination extensions and spatial load tests. Semantic deduplication cannot guarantee that independently created reports of the same defect will always match.

## Evidence and sharing

Uploads accept decodable JPEG, PNG and WebP, at most 8 MB locally (4 MB in AWS mode) and 20 million pixels. AWS report attachments are also capped at 4 MB in total before approval and before any portal call, leaving room for base64 and multipart transport through Lambda. Uploaded bytes are decoded, orientation-normalized, resized, and re-encoded into a fresh RGB JPEG without EXIF. Only the sanitized derivative is retained; original uploaded bytes are discarded rather than published. The local file is private mode 0600, or encrypted in private S3 in AWS. The API scopes downloads to the owner, or an explicitly shared sanitized image on a shared incident. Local authorization is checked on every read; AWS materialization uses a private, hash-verified cache. Session authorization expires after seven days; no permanent public original URL exists.

Metadata stripping does not remove faces, license plates, or sensitive visible content. Residents must review the sanitized preview and exclude sensitive photos; automated visual redaction is not implemented. Early community-summary sharing is separate from agency submission approval. Sharing photos requires an additional explicit `share_evidence` consent, defaulting to false; consent to share a summary never publishes its photos. Other residents never receive private contacts, private evidence paths, approval records, task tokens, or private receipt links. Captured browser screenshots are masked by the adapter, saved as private evidence, and shown only to the reporting owner.

Agency status and physical resolution are independent. Closure, including closure as a duplicate, requests optional verification rather than declaring a fix. “Still present” and “Unable to verify” do not send any follow-up or escalation. Outbound follow-ups remain assisted handoff and require new approval before a future implementation sends them.

## Verification

`./.venv/bin/python -m pytest tests/test_domain.py -q` tests the local domain and HTTP authorization boundary with deterministic model fixtures and a browser double. Actual browser submission and portal tests are separate (`tests/test_browser.py`, `tests/test_portal.py`); AWS smoke tests are explicitly gated. Domain test results do not establish deployed AWS availability or real municipal integration.
